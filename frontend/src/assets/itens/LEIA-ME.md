# Imagens dos itens (aba "Por NPC")

Coloque aqui uma imagem `.gif` por item, com o nome em minúsculas e hífens no
lugar de espaços e símbolos:

| Item | Arquivo |
|---|---|
| Banana Sash | `banana-sash.gif` |
| Spellweaver's Robe | `spellweaver-s-robe.gif` |
| Darklight Core (Item) | `darklight-core-item.gif` |

- Item sem imagem aparece com um quadradinho no lugar; não quebra nada.
- Depois de colocar imagens, rode `npm run build` (ou faça o deploy) para elas aparecerem.
- O crédito "Imagens dos itens: Tibia Wiki" aparece sozinho no rodapé do site
  enquanto houver ao menos uma imagem aqui. As imagens vêm da Tibia Wiki
  (tibiawiki.com.br), como explica a seção de fontes do README da raiz.
